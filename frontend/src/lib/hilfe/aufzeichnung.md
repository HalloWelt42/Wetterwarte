# Aufzeichnung

Die Wetterwarte kann Messwerte dauerhaft mitschreiben, damit ein eigenes
Langzeit-Archiv entsteht. Den Manager erreichst du links über **Aufzeichnung**.

## Was aufgezeichnet wird

Je Ort wählst du, welche Größen mitgeschrieben werden:

- **Temperatur**, **Luftfeuchte**, **Wind**, **Luftdruck**
- **Luftqualität**: AQI, Feinstaub PM2,5 und PM10, Ozon, Stickstoffdioxid

Jede Größe lässt sich einzeln an- und abwählen, und die Aufzeichnung eines Ortes
lässt sich ganz **pausieren**. Der Manager zeigt je Ort, wie viele Messwerte schon
gesammelt wurden.

## Wie oft

Im Hintergrund werden die aktuellen Werte regelmäßig (etwa alle zehn Minuten)
fortgeschrieben. Beim ersten Start wird die Temperatur der letzten Wochen einmalig
aus dem Archiv vorbefüllt, damit sofort etwas zu sehen ist.

## Wozu

Aus diesen Messwerten entstehen die Auswertungen unter *Archiv und Analyse* -
etwa das Jahresmesswerte-Diagramm. Je länger die Wetterwarte läuft, desto reicher
wird dein eigenes Archiv.
